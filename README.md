# Fundamentos de Análise de Dados · Turma A

Site da disciplina Fundamentos de Análise de Dados (Especialização em Análise de Dados e Inteligência Artificial, CESAR School), Turma A. Prof. Laura Pacifico.

- `index.html`: página inicial
- `aulas/`: as aulas interativas dos 7 encontros
- `laboratorio/`: o Laboratório do Projeto
- `guia/`: o guia de estudo, para ler online e em PDF
- `bases/`: as bases .csv usadas nas aulas

Publicado com GitHub Pages a partir da raiz da branch `main`.
