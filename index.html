Laboratório do Projeto

Para o trabalho em grupo. Carreguem a base do grupo e sigam as etapas: raio-X, limpeza, novas colunas, outliers e hipóteses. Cada etapa copia o resultado para a aba certa do Excel.

A base não sai do seu computador: fica só neste navegador.

Como usar as aulas

Algumas dicas para aproveitar os laboratórios.

  • Prefira o computador

    As aulas funcionam no celular, mas arrastar, comparar e copiar para o Excel é mais confortável numa tela grande.

  • Modo aula

    O botão Modo aula mostra uma parte por vez, como slides. Use as setas para avançar e voltar.

  • Suas respostas ficam salvas

    O que você escreve nas atividades fica guardado neste navegador. Use o botão Copiar para levar tudo ao Excel.

  • Quer ver a conta?

    Os laboratórios têm “Como isso é calculado?” no final, para quem quiser entender o cálculo.
